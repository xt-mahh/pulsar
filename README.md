# Pulsar · 脉冲星

> **Universal Social Media Operator Agent**  
> 通用社交媒体操作代理

---

## 名字的由来

**脉冲星（Pulsar）** 是一种高速自转的中子星，以其极其精准、稳定的脉冲信号闻名。无论相隔多远，脉冲星都能跨越宇宙尺度，向地球发送清晰可辨的信号。

Pulsar 项目取其名，意在传达同样的愿景：**跨平台、精准、可靠地发布和管理社交媒体内容**。就像脉冲星把信号传遍星际空间，Pulsar 把你的内容送达每一个社交平台。

---

## 系统架构

Pulsar 采用 **五层架构**，从底层运行时到顶层交互，层层解耦、职责分明：

```
┌─────────────────────────────────────┐
│         Interaction Layer           │  ←  CLI / API / Web 界面
├─────────────────────────────────────┤
│         Execution Layer             │  ← 平台适配器（WeChat, Weibo…）
├─────────────────────────────────────┤
│           Task Layer                │  ← 任务编排 & 状态机
├─────────────────────────────────────┤
│         Cognition Layer             │  ← LLM 推理 / 意图理解 / 规划
├─────────────────────────────────────┤
│          Runtime Layer              │  ← 基础框架 / PIP / 配置
└─────────────────────────────────────┘
```

| 层级 | 职责 |
|------|------|
| **Runtime** | 基础框架、PIP 协议通信、配置加载、日志、错误处理 |
| **Cognition** | LLM 网关、意图识别、对话管理、内容生成 |
| **Task** | 任务编排、状态机、多步工作流、重试 & 回滚 |
| **Execution** | 平台适配器、API 封装、限频处理、认证管理 |
| **Interaction** | CLI（click + rich + prompt_toolkit）、后续支持 Web API |

层间通过 **PIP（Pulsar Internal Protocol）** 定义的标准接口通信，每一层都可以独立替换或扩展。

## 快速开始

### 安装

```bash
# 从源码安装（推荐）
git clone https://github.com/xt-mahh/pulsar.git
cd pulsar
pip install -e ".[dev]"

# 或直接使用 pip 从 GitHub 安装
pip install git+https://github.com/xt-mahh/pulsar.git
```

### 使用

启动 Pulsar 交互式 CLI：

```bash
pulsar
```

然后在对话中输入你想做的事情：

```
> 帮我写篇文章
```

Pulsar 会通过自然语言对话理解你的需求，生成文章内容，并引导你完成发布流程。

### 示例对话

```
> 帮我写篇文章

Pulsar: 好的！请问这篇文章的主题是什么？
> 介绍一下脉冲星

Pulsar: 很好！文章风格你希望是科普类还是专业类？
> 科普类

Pulsar: 好的，我为你生成了一篇科普文章，预览如下：

   ┌─────────────────────────────────────┐
   │  宇宙的灯塔：脉冲星                 │
   │  在浩瀚的宇宙中，有一种奇特的天体…  │
   └─────────────────────────────────────┘

   是否要发布到微信公众号？（y/n）
> y

Pulsar: 文章已发布到微信公众号「我的账号」✅
```

## 技术栈

| 技术 | 用途 |
|------|------|
| **Python 3.11+** | 主开发语言 |
| **PIP Protocol** | 层间通信协议 |
| **LLM Gateway** | 大模型推理与内容生成 |
| **click** | CLI 命令框架 |
| **rich** | 终端美化与格式化输出 |
| **prompt_toolkit** | 交互式对话界面 |

## 项目阶段

### Phase 1（当前）
- 仅支持 **微信公众号** 平台
- **对话优先** CLI 交互模式
- 全中文界面与文档
- 基础文章生成与发布流程

### Phase 2（规划中）
- 支持更多平台（微博、知乎、小红书等）
- Web API 接口
- 定时发布与内容日历
- 多账号管理
