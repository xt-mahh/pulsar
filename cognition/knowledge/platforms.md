# 各内容平台概览

## 微信公众号 (WeChat Official Account)

| 属性 | 说明 |
|------|------|
| 平台类型 | 图文内容平台（订阅号/服务号） |
| 内容形式 | 图文消息、视频消息 |
| API 开放程度 | ⭐⭐⭐ 中高（企业认证后较完善） |
| 核心 API | 草稿管理、发布、素材管理、评论管理、用户管理、数据统计 |
| 发布限制 | 订阅号 1 次/天，服务号 4 次/月 |
| 适合内容 | 深度文章、行业分析、品牌故事 |

## 微博 (Weibo)

| 属性 | 说明 |
|------|------|
| 平台类型 | 社交媒体平台 |
| 内容形式 | 微博（文字+图片/视频）、头条文章 |
| API 开放程度 | ⭐⭐⭐ 高（开放平台完善） |
| 核心 API | 微博发布、图片上传、评论管理、数据统计 |
| 发布限制 | 无严格数量限制 |
| 适合内容 | 实时资讯、短内容、话题讨论 |

## 小红书 (Xiaohongshu / RED)

| 属性 | 说明 |
|------|------|
| 平台类型 | 生活方式社区 |
| 内容形式 | 图文笔记、视频笔记 |
| API 开放程度 | ⭐ 低（企业号 API 限制严格） |
| 核心 API | 笔记发布、评论管理（需企业号） |
| 发布限制 | 企业号有频率限制 |
| 适合内容 | 种草推荐、教程攻略、生活方式 |

## B 站 (Bilibili)

| 属性 | 说明 |
|------|------|
| 平台类型 | 视频社区 |
| 内容形式 | 视频、专栏文章、动态 |
| API 开放程度 | ⭐⭐ 中高（需创作中心接入） |
| 核心 API | 视频上传、专栏发布、动态发布、评论管理 |
| 发布限制 | 无严格数量限制 |
| 适合内容 | 视频内容、深度专栏、二次元/知识区 |

## 抖音 (Douyin / TikTok)

| 属性 | 说明 |
|------|------|
| 平台类型 | 短视频平台 |
| 内容形式 | 短视频、图文、直播 |
| API 开放程度 | ⭐⭐ 中高（企业号/服务商接入） |
| 核心 API | 视频发布、图文发布、数据统计 |
| 发布限制 | 企业号有频率限制 |
| 适合内容 | 短视频、娱乐内容、产品展示 |

## 今日头条 (Toutiao)

| 属性 | 说明 |
|------|------|
| 平台类型 | 资讯聚合平台 |
| 内容形式 | 文章、微头条、视频 |
| API 开放程度 | ⭐⭐ 中 |
| 核心 API | 文章发布、微头条发布、数据统计 |
| 发布限制 | 无严格数量限制 |
| 适合内容 | 新闻资讯、热点评论、知识科普 |

## 知乎 (Zhihu)

| 属性 | 说明 |
|------|------|
| 平台类型 | 知识问答社区 |
| 内容形式 | 回答、文章、想法 |
| API 开放程度 | ⭐⭐ 中（开放 API 有限） |
| 核心 API | 回答发布、文章发布、评论管理 |
| 发布限制 | 无严格数量限制 |
| 适合内容 | 专业问答、深度分析、知识分享 |
