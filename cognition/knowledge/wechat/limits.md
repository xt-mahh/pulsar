# 微信公众号 API 限制说明

## Access Token 限制

| 项目 | 限制值 |
|------|--------|
| 有效期 | 7,200 秒（2 小时） |
| 获取频率 | 每日最多 10,000 次（普通 token） |
| 稳定版 token | 无频率限制（推荐用于定时任务） |
| 缓存策略 | 本地缓存至过期前 600 秒刷新 |

## 接口调用频率限制

### 基础接口
| 接口 | 频率限制 |
|------|----------|
| 获取 token | 10,000 次/天 |
| 获取稳定版 token | 无限制 |
| 获取微信服务器 IP | 无限制 |

### 素材管理
| 接口 | 频率限制 |
|------|----------|
| 上传临时素材 | 5,000 次/天 |
| 上传永久素材 | 1,000 次/天 |
| 获取素材列表 | 500 次/天 |
| 删除素材 | 500 次/天 |

### 草稿管理
| 接口 | 频率限制 |
|------|----------|
| 创建草稿 | 500 次/天 |
| 修改草稿 | 500 次/天 |
| 获取草稿列表 | 500 次/天 |
| 删除草稿 | 500 次/天 |

### 发布管理
| 接口 | 频率限制 |
|------|----------|
| 提交发布 | 500 次/天 |
| 发布状态查询 | 500 次/天 |
| 发布次数查询 | 100 次/天 |

### 数据统计
| 接口 | 频率限制 |
|------|----------|
| 用户分析 | 100 次/天 |
| 图文分析 | 100 次/天 |
| 消息分析 | 100 次/天 |
| 接口分析 | 100 次/天 |

### 评论管理
| 接口 | 频率限制 |
|------|----------|
| 打开/关闭评论 | 500 次/天 |
| 精选评论 | 500 次/天 |
| 删除评论 | 500 次/天 |
| 回复评论 | 500 次/天 |

## 素材有效期

| 素材类型 | 有效期 |
|----------|--------|
| 临时素材 | 3 天 |
| 永久素材 | 永久（有数量上限） |
| 图文消息 | 发布后长期有效 |

## 永久素材数量上限

| 素材类型 | 上限 |
|----------|------|
| 图片 | 10,000 个 |
| 语音 | 1,000 个 |
| 视频 | 1,000 个 |
| 缩略图 | 10,000 个 |

## 草稿数量限制

- 草稿箱最多保存 **100 篇** 草稿
- 超出后需删除旧草稿才能创建新草稿

## 发布限制

| 公众号类型 | 每日发布次数 |
|------------|-------------|
| 订阅号 | 1 次（可包含最多 8 篇图文） |
| 服务号 | 每月 4 次 |

## 错误码参考

| 错误码 | 说明 | 处理方式 |
|--------|------|----------|
| -1 | 系统繁忙 | 重试 |
| 0 | 请求成功 | - |
| 40001 | access_token 无效 | 重新获取 token |
| 40002 | 不合法的凭证类型 | 检查 app_id |
| 40003 | 不合法的 OpenID | 检查用户 ID |
| 40004 | 不合法的媒体文件类型 | 检查素材格式 |
| 40005 | 不合法的文件类型 | 检查文件格式 |
| 40006 | 不合法的文件大小 | 检查文件大小 |
| 40007 | 不合法的媒体文件 id | 检查 media_id |
| 40009 | 不合法的图片大小 | 检查图片尺寸 |
| 40013 | 不合法的 AppID | 检查 app_id 配置 |
| 40014 | 不合法的 access_token | token 过期，重新获取 |
| 40035 | 不合法的参数 | 检查请求参数 |
| 40164 | IP 不在白名单 | 添加服务器 IP 到白名单 |
| 41001 | 缺少 access_token | 补充 token |
| 41002 | 缺少 appid | 补充 app_id |
| 41003 | 缺少 refresh_token | 补充 refresh_token |
| 42001 | access_token 超时 | 重新获取 token |
| 42002 | refresh_token 超时 | 重新授权 |
| 43001 | 需要 GET 请求 | 改用 GET 方法 |
| 43002 | 需要 POST 请求 | 改用 POST 方法 |
| 44001 | 多媒体文件为空 | 检查文件内容 |
| 44002 | POST 的数据包为空 | 检查请求体 |
| 45001 | 多媒体文件大小超过限制 | 压缩文件 |
| 45002 | 消息内容超过限制 | 缩短内容 |
| 45009 | 接口调用超过限制 | 等待后重试 |
| 48001 | api 功能未授权 | 检查公众号权限 |
| 50001 | 用户未授权该 api | 重新授权 |
