# 微信公众号 API 限制说明

## 频率限制
| API | 限额 |
|-----|------|
| access_token 获取 | 2000 次/天 |
| 草稿创建 | 无明确限制（建议 ≤ 100/天） |
| 发布提交 | 与群发次数一致 |
| 素材上传 | 500 次/天 |
| 数据统计 | 1 次/分钟 |

## Token 有效期
- access_token: 7200 秒
- 建议提前 300 秒刷新
- 稳定版 token: 通过 POST /cgi-bin/stable_token 获取

## 内容限制
- 单篇草稿 ≤ 20000 字符
- 封面图 ≤ 10MB
- 正文图片 ≤ 2MB
- 音频 ≤ 200MB（200 分钟）
- 视频 ≤ 20MB
