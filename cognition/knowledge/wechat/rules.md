# 微信公众号运营规则

## 内容规范

### 标题规则
- 标题长度限制：**32 字以内**（超出会被截断）
- 建议标题长度：15-25 字为最佳
- 禁止使用夸张、虚假标题（标题党）
- 标题中禁止使用特殊符号如 ★、●、◆ 等

### 正文规则
- 正文最大长度：**20,000 字符**（含 HTML 标签）
- 建议正文长度：1,500-3,000 字为最佳阅读长度
- 支持 HTML 格式排版
- 正文中的图片必须通过微信素材接口上传获取 URL
- 禁止包含诱导分享、关注内容

### 封面图规则
- 建议尺寸：**900×500 像素**（16:9 比例）
- 支持格式：JPG、PNG、GIF
- 文件大小：不超过 10MB
- 封面图中禁止包含二维码、联系方式

### 摘要规则
- 摘要长度限制：**128 字以内**
- 不填写摘要时，微信自动抓取正文前 54 字
- 建议手动填写摘要以提升打开率

### 作者信息
- 作者名长度限制：**16 字以内**
- 可自定义作者名

## 原创声明

- 原创文章需 300 字以上
- 原创声明后不可修改文章内容
- 抄袭/洗稿会被取消原创资格
- 原创文章可开通赞赏功能

## 违规内容

| 违规类型 | 处罚措施 |
|----------|----------|
| 政治敏感 | 删文 + 封号 |
| 色情低俗 | 删文 + 警告/封号 |
| 虚假信息 | 删文 + 限制功能 |
| 诱导分享 | 删文 + 限制分享 |
| 抄袭侵权 | 删文 + 取消原创 |
| 恶意营销 | 限制功能/封号 |

## 发布限制

| 公众号类型 | 发布频率 |
|------------|----------|
| 订阅号 | 每天 1 次群发 |
| 服务号 | 每月 4 次群发 |
| 企业号 | 无限制（但需认证） |

## 最佳实践

1. **发文时段**：早 8-9 点、午 12-13 点、晚 20-22 点为最佳
2. **排版建议**：段落不超过 5 行，多使用小标题和图片分隔
3. **互动策略**：引导评论、设置话题讨论、回复精选评论
4. **数据分析**：关注打开率、分享率、完读率三个核心指标
